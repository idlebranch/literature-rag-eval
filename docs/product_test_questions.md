# Historical Product Test Question Set (pre-freeze)

> This question set belongs to the early `data/pdfs` corpus stage. It is not the
> v1.0.0 acceptance set and does not describe the final runtime or metrics.

用于产品可用性测试与 RAG 质量手工评测。所有问题基于 `data/pdfs/` 中的环境工程文献设计。

---

## 1. 文献库总览 (Collection Overview)

验证系统对文献库整体构成的掌握程度。

| # | 问题 | 预期要点 |
|---|------|----------|
| 1.1 | 当前文献库主要覆盖了哪些水处理技术路线？ | 应列出 AOPs、吸附、臭氧、光催化、Fenton、PFAS 去除等路线，每类至少 1 条 |
| 1.2 | 文献库中关于 PFAS 的文献主要讨论了哪几个方面？ | 应覆盖去除技术、降解机理、工程限制等维度 |
| 1.3 | 哪些文献涉及真实水体实验（非纯水/去离子水）？ | 应能引用具体 source，并说明实验条件 |

---

## 2. 单篇事实问题 (Single-Paper Factual)

验证对单篇文献关键信息的精确召回。

| # | 问题 | 预期要点 |
|---|------|----------|
| 2.1 | 文献中关于 PAC 去除 SMX 的主要吸附机制是什么？ | 应引用具体来源，给出静电力、π-π 等机制，并标注具体页码 |
| 2.2 | 某篇文献中使用的催化剂是什么？负载量/掺杂比例是多少？ | 应精确引用文中数字，不可泛泛而谈 |
| 2.3 | 文献中报道的 PMS 活化降解某污染物的最优 pH 是多少？为什么？ | 应给出具体数值和文献解释 |

---

## 3. 多文献比较 (Cross-Paper Comparison)

验证对不同文献结论的对比整合能力。

| # | 问题 | 预期要点 |
|---|------|----------|
| 3.1 | 比较吸附法和 AOPs 法去除 PFAS 的优缺点 | 应分条对比：去除率、能耗、副产物、适用场景各列一节 |
| 3.2 | 臭氧氧化、PMS 活化、光催化三者对抗生素的降解效率有何差异？ | 应分技术路线独立讨论，不能合并成一段 |
| 3.3 | 文献库中不同催化剂在 PMS 活化中的性能排序如何？ | 应有对比表格或清晰排序，注明各催化剂的条件差异 |
| 3.4 | 关于 NOM/DOM 对 AOPs 的影响，不同文献的结论是否一致？有不一致的地方应指出 | 应区分一致结论与争议点 |

## 4. 机制归纳 (Mechanism Synthesis)

验证从多篇文献中归纳共性机制的能力。

| # | 问题 | 预期要点 |
|---|------|----------|
| 4.1 | AOPs 体系中主要的活性氧物种（ROS）有哪些？各自的生成路径和贡献？ | 应区分自由基（•OH, SO₄•⁻, O₂•⁻）与非自由基（¹O₂, 高价金属），给出生成条件 |
| 4.2 | 碳基催化剂（生物炭、碳纳米管、g-C₃N₄ 等）在 AOPs 中的作用机制是什么？ | 应覆盖吸附富集、电子转移、活性位点、缺陷工程等 |
| 4.3 | 催化剂失活的主要原因有哪些？文献中提出了哪些再生方法？ | 应分类汇总（金属浸出、积碳、活性位点氧化等），注明各方法的有效性 |

## 5. 反幻觉边界问题 (Anti-Hallucination Boundary)

验证系统在信息不足或不相关时的诚实度。

| # | 问题 | 预期要点 |
|---|------|----------|
| 5.1 | 文献库中关于电化学氧化处理 PFAS 的能量消耗数据是多少？ | 如果文献库有则引用；没有则必须声明"当前检索材料不足以回答" |
| 5.2 | 哪篇文献报道了中试规模的 AOPs 处理 PFAS 实验？ | 如无中试文献，应明确说明检索材料不足 |
| 5.3 | C 催化剂和 D 催化剂在 pH=3 条件下降解苯酚的速率常数分别是多少？ | 如文献库中无此催化剂或无此条件数据，必须拒答 |
| 5.4 | 文献库中最新的文献是哪一年的？是否有 2026 年的文献？ | 应基于 metadata 诚实回答年份范围，不可编造 |
| 5.5 | 请用一段话总结文献库中关于超声降解 PFAS 的研究进展 | 如无相关文献，应声明不足；不能编造任何超声相关内容 |

## 6. 文献综述生成 (Mini-Review Generation)

验证系统整合多源信息生成综述性文本的能力。

| # | 问题 | 预期要点 |
|---|------|----------|
| 6.1 | 请撰写一篇关于"非均相催化活化 PMS 降解新污染物"的微型综述（500-800 字），包含：引言、催化剂分类、机理、影响因素、挑战与展望 | 每节应有 [Sx] 引用标注，结构完整，不应有未标注的断言 |
| 6.2 | 总结文献库中关于真实水体基质对 AOPs 效能影响的研究，按水体类型（地表水、地下水、污水厂出水）分别讨论 | 应分类型讨论，如某类型无材料应标明 |
| 6.3 | 基于文献库现有材料，绘制一个"PFAS 处理技术决策树"（文本描述即可），考虑浓度、水体类型、处理目标等因素 | 应有分支逻辑，每级有文献支撑 |

## 使用说明

1. **测试前**：确保已运行 `python -m src.ingest` 建好索引
2. **逐个测试**：将问题逐条输入 Streamlit 前端，记录回答质量
3. **评分维度**：
   - **准确性**：结论是否与文献原文一致
   - **完整性**：是否覆盖了问题的所有子维度
   - **诚实度**：信息不足时是否明确声明
   - **可溯源**：每个关键结论是否有 [Sx] 标注
4. **记录方式**：在 `outputs/` 下保存每次测试的 Q&A 结果

## 预期 Badcase 类型

| 类型 | 描述 | 对应问题 |
|------|------|----------|
| hallucination | 编造文献中不存在的数据或结论 | 5.1-5.5 |
| incomplete | 只回答了部分子问题 | 3.1-3.4, 4.2 |
| missing_source | 结论没有标注来源 | 6.1-6.3 |
| over_merge | 多技术路线被合并为一段，未分别讨论 | 3.2, 6.2 |
| false_confidence | 信息不足但强行给出肯定结论 | 5.1-5.5 |
